# Guide de test — KORTEX Prospect

Une page à la fois, dans l'ordre. Coche chaque ligne quand elle marche ; note ce qui coince.
Durée totale : environ 45 minutes.

## 0. Avant de commencer (5 min)

- [ ] **Paramètres** : les cartes *LLM* et *Recherche web Tavily* sont cochées. Clique **Tester** sur le LLM → un message « Réponse du modèle : OK ».
- [ ] **Bibliothèque documentaire** : clique dans la zone pointillée → choisis `CV_Shalom_Tehe_FR_2026-11.pdf` → la catégorie passe seule à « CV français » → **Ajouter**. Pareil pour le CV EN.
- [ ] Ajoute aussi la **plaquette KORTEX** (`KORTEX_KIT_PME/A_ENVOYER_PDF_JPG/KORTEX_Plaquette.pdf`) et le **certificat CEPICI**.

## 1. Trouver des offres (10 min)

- [ ] **Offres d'emploi** → **Rechercher** (mots-clés déjà remplis) → des notifications « remotive : N nouvelle(s)… » apparaissent, la liste se remplit.
- [ ] Filtre **Score ≥ 70** → la liste se réduit.
- [ ] Panneau **Plateformes** → clique **LinkedIn Jobs** → LinkedIn s'ouvre avec la recherche préremplie.
- [ ] Copie le texte d'une annonce LinkedIn → **Importer une annonce** → colle → **Importer** → l'offre apparaît, avec un score.
- [ ] **Missions freelance** → **Rechercher** → même principe.

## 2. Analyser une offre (5 min)

- [ ] Ouvre une offre avec un bon score → **Analyser (IA)** → le score passe en « IA », chaque critère a une explication, les *points de vigilance* s'affichent.
- [ ] Change le statut en haut (ex. « Pertinent ») → l'historique en bas affiche le changement.
- [ ] Renseigne une **prochaine action** avec une date de demain → **Enregistrer** → elle apparaît sur le **Dashboard** dans « Actions à faire ».

## 3. Lettre et email (5 min)

- [ ] Dans l'offre, *Lettres et emails* : « Lettre de motivation », « English » → **Générer** (≈ 20 s) → une lettre apparaît.
- [ ] Modifie une phrase → **Enregistrer** → la mention « modifié » apparaît.
- [ ] **PDF** puis **DOCX** → les fichiers se téléchargent, en noir et blanc.
- [ ] Choisis « Email d'accompagnement » → **Générer** → un email court qui résume la lettre.

## 4. Préparer une candidature (5 min)

- [ ] Dans l'offre → **Préparer la candidature** → tu arrives sur l'écran de préparation.
- [ ] Clique **Ajouter les recommandées** → le CV EN est coché. Choisis la lettre dans « Lettre / proposition à joindre ».
- [ ] Les boutons de brouillon sont grisés → coche les 3 vérifications → ils s'activent.
- [ ] S'il n'y a pas d'email : **Postuler sur le site** depuis la fiche, puis reviens et clique **Confirmer l'envoi manuel**.
- [ ] **Préparation des candidatures** : la candidature apparaît « Envoyée manuellement » ; l'offre a une relance à J+7.

## 5. Entreprises (10 min)

- [ ] **Recherche d'entreprises** → secteur « Banque », ville « Abidjan » → **Rechercher** → des entreprises arrivent, « à qualifier ».
- [ ] Ouvre une entreprise **sans site** → **Trouver le site officiel** → choisis le bon → **C'est celui-ci** → le scan démarre seul.
- [ ] Ouvre une entreprise **avec site** → **Scanner le site** → emails, téléphones, formulaire apparaissent avec leur source.
- [ ] **Analyser (IA)** → score et approche recommandée.
- [ ] **Ajouter une entreprise** (bouton en haut) avec un site que tu connais → contacts trouvés automatiquement.

## 6. CRM (5 min)

- [ ] **Suivi et CRM** → les cartes sont rangées par colonne de statut.
- [ ] **Glisse** une carte d'une colonne à l'autre → son statut change (vérifie dans sa fiche).
- [ ] Onglets **Shalom / KORTEX** → le tableau se filtre.
- [ ] Dans une fiche, *Historique des échanges* → type « Réponse reçue », résumé « Mail de la DRH » → **Ajouter** → la carte passe en « Réponse reçue » ; le compteur *Réponses reçues* du Dashboard augmente.
- [ ] Même chose avec « Rendez-vous programmé » → compteur *Rendez-vous obtenus*.

## 7. Campagne KORTEX (sans envoyer) (5 min)

- [ ] **Campagnes** → coche 2 entreprises qui ont un email → **Rédiger 2 email(s)** → l'écran du lot affiche « Rédaction en cours » puis les emails.
- [ ] Lis les alertes sous chaque email, modifie, **Réécrire** un email.
- [ ] Les prospects écartés sont listés avec la raison.
- [ ] Ne valide pas tant que `MAIL_PASSWORD` n'est pas configuré (le bouton refusera de toute façon).

## Si quelque chose ne marche pas

- Un message rouge apparaît en haut à droite : copie-le tel quel.
- Rien ne se passe du tout : rafraîchis la page (Ctrl+F5) ; si ça persiste, note la page et le bouton.
